## 1. The problem

P1 Registry registered the MARKET_RELATIVE family (F15/F16/F17, `REL_RET1/5/20`) with
`expected_direction = POSITIVE`. P1 Discovery observed:

- `REL_RET1` Discovery mean daily CS IC ≈ −0.034 (vs registered POSITIVE)
- `REL_RET5` ≈ −0.051
- `REL_RET20` ≈ −0.045
- BH q(m=17) ≈ 0.009 (passes the raw multiple-testing bar)

The original P1 report phrased this as *"relative-strength family 被推翻 / registered direction violated."*
That phrasing is **incorrect** for this framework and is hereby corrected.

## 2. Formal argument: rank invariance within a day

The feature is constructed as:

```
REL_RETk(i,t) = RETk(i,t) − EW_k(t)      for k ∈ {1, 5, 20}
```

where `EW_k(t)` is the All-A equal-weighted index k-day compounded return — a **single scalar
common to every stock on date t** (see `build_predictor_frame` in `cross_sectional_ranking_p1.py`).

Within any fixed signal date `t`, for any two stocks i, j:

```
REL_RETk(i,t) − REL_RETk(j,t) = RETk(i,t) − RETk(j,t)
```

Adding the same constant `EW_k(t)` to every stock's value is a strictly monotone transformation.
Therefore, **within a day, the cross-sectional rank of REL_RETk is exactly the cross-sectional
rank of RETk**:

```
rank_t(REL_RETk) ≡ rank_t(RETk)   (up to NaN propagation)
```

Consequently every within-day statistic in the P1 framework — daily cross-sectional Spearman IC,
oriented pairwise accuracy, quintile membership, top-K selection — is **identical** between
`REL_RETk` and `RETk`.

## 3. Empirical confirmation (P1.1 corrected run)

| pair | construction | day-level IC series |

| F05 `RET5` vs F16 `REL_RET5` | `RET5 − EW5` | identical (n=534; mean −0.0538; median −0.0691; pos_frac 0.3764; HAC t −3.29; raw p 0.0010; BH q 0.0015) |

Yearly ICs (2020/2021/2022) are also identical for each pair. The only possible divergence is
NaN propagation: on a date where `EW_k(t)` is NaN, `REL_RETk` is NaN for **all** stocks that date
while `RETk` may remain valid; under the per-day ≥5-valid-signal gate this produces no practical
difference in the used day sets.

## 4. Corrected conclusion

> **Simple market subtraction is rank-invariant within day; therefore this formulation cannot
> test market-relative ranking.**

Correct statements:

- F15/F16/F17 are **not independent predictors** in this cross-sectional ranking framework.
- They do **not** constitute an independent "relative-strength family" finding.
- They do **not** provide evidence against or for market-relative weakness as a concept —
  the P1 formulation simply cannot distinguish it from plain k-day return.
- Their registered POSITIVE orientation could not be falsified in a meaningful way: the
  measured "opposite direction" is identical to the plain-return family's (UNKNOWN) direction.

## ② 严格 A 股成交模拟 — PASS（策略逻辑天然规避）

在 fast 引擎新增 `execution_constraints` 开关，模拟：**一字涨停买不到 / 跌停卖不掉 / 一字板 / 开盘无法成交**（涨停判定按主板10%、创业板/科创板20%、ST 5%的 corrected 口径）。

| 成交约束 | 执行时点 | 含ETF | 股票核心 |
|---|---|---|---|
| OFF | close | +226.5% | +114.8% |
| **ON** | **close** | **+226.5%** | **+114.8%** |
| OFF | next_open | +233.0% | +118.6% |
| **ON** | **next_open** | **+233.0%** | **+118.6%** |

**成交约束 ON 与 OFF 收益完全相同**。原因（量化验证）：

1. **买入侧**：630个买入信号日中，**涨停 0 个、一字涨停 0 个**（跌停11.4%已被原逻辑过滤）。策略要求"收盘价跌破布林下轨"才买入——超跌股当日不可能涨停，**涨停买不到的约束在策略路径上从不触发**。
2. **卖出侧**：38笔止盈出场日**跌停 0 个**。策略要求"盘中最高价触上轨"才止盈——涨到上轨的股票当日不可能跌停，**跌停卖不掉也不触发**。
3. **流动性**：39笔买入日成交额（amount，Tushare单位=千元）**最小20亿元、中位100亿元**。单笔投入20-100万仅占当日成交额的**<0.05%**，无冲击。容量验证：即便单笔放大到1000万仍仅占0.5%。
4. **next_open 约束下 +233.0%（含ETF）/ +118.6%（核心）**，略高于 close 版——与第二轮一致：买的是超卖股，T+1开盘自带反弹优势，收盘成交假设偏保守而非乐观。

**剩余假设（必须标注）**：日线模型无法判断盘中实际成交时刻（EXACT 级别只能到"收盘价/开盘价成交"近似）。极端跳空（如停复牌后连续一字）在39笔中未出现，但理论上 day-1 停牌 → 复牌一字涨停的"买不进"仍可能发生，本模型按收盘价近似成交。此为 APPROXIMATION，非 UNSUPPORTED。

## ④ Monte Carlo / Permutation Reality Check — 🟡 边缘显著（本轮最重要发现）

对"如果完全没有Alpha，+114.8%（股票核心）有多容易随机产生"做两种结构性置换（均保持真实成本权重=levels×20万）：

| Null 设计 | 打破的维度 | 保持的维度 | null 中位数 | 5% | 95% | p值 |
|---|---|---|---|---|---|---|
| **A 随机选股** | 选股（538只候选池内随机） | 真实进场/出场时间 | -8.3万 | -111.3万 | +147.6万 | **0.084** |
| **B 随机择时** | 择时（随机入场日） | 真实股票+持仓天数 | +27.6万 | -88.4万 | +169.6万 | **0.130** |

（注：原"收益无放回permutation"方案因可加统计量对置换不变，属统计错误，已废弃。）

**诚实解读**：
- 真实累计 PnL = 114.8万，处于随机选股 null 的 **91.6%分位**（p=0.084）。
- **两种结构性置换 p 值均介于 0.08~0.13，未达传统 0.05 显著线**。这意味着：**策略的优势是"超跌选股 + 择时"的组合，单独剥离任一维度后，其超额是边缘显著而非压倒性**。
- 部分收益与 Top10 大盘股池的 **beta + 2020-2026 牛市背景**相关（null 中位数接近0、右尾厚：同样时间窗口随机持有Top10池股票也有相当概率赚钱）。
- 对比第三轮 bootstrap（P(>0)=100%，非常显著）：bootstrap 回答"给定这39笔收益，分布是否稳定为正"（是）；permutation 回答"打破选股/择时结构后，随机能否复现"（边缘）。**两者合起来 = 收益稳定为正，但结构性Alpha幅度有限**。
- 方法A的权重（levels×20万）未含加仓增强放大，null 偏保守（真实显著性或略高于0.084）；方法B保持真实持仓天数、随机入场日，未含超跌条件，是"任意日买入持有"基线。

**结论**：+114.8% 不能被称为"压倒性Alpha"，应表述为"**边缘显著的选股/择时信号 + 大盘池beta + 牛市环境**的组合，正向收益在统计上稳定（bootstrap），但结构性的超额在单一维度上只有边缘证据（p≈0.08-0.13）"。

**不改动策略逻辑，只叠加更真实的交易规则**（correct涨跌停 + 历史印花税 + 10bp滑点 + 成交约束，均已在①-⑤量化）：

| 10bp滑点 + 正确涨跌停 + 历史印花税 + 成交约束（含ETF） | **≈ +219.6%** | **≈ 97%** |
| 其中股票核心（剥离ETF） | **≈ +109.7%** | — |
| 50bp极端成本（含ETF） | +189.9% | 84% |

**但注意**：上述"保留97%"回答的是**收益数字对交易规则修正的稳健性**（几乎全部保留）。它**不回答"这是否是可交易Alpha"**——后者由④Permutation决定：**结构性Alpha边缘显著（p≈0.08-0.13）**。

**最终结论（确定性，非"大概率"）**：
- 在更接近真实A股交易规则的模型下，**+226.75% 的收益数字几乎全部保留（≈97%，成本50bp极端下仍有84%）**，成本/成交约束/复权/印花税/T+1/幸存者偏差**均不构成摧毁性因素**。
- 但该收益的**结构性Alpha证据为边缘显著**（permutation p≈0.08-0.13），不能称为"已证明的可交易Alpha"；它是"超跌反弹信号 + Top10大盘池beta + 牛市环境"的组合。
- **评级：A / Strong evidence（第三轮）→ 本轮新增"成本/成交/PIT PASS + Permutation边缘"**。距"小资金实盘验证资格(A+)"只差：**未来盲测实证**（至少12个月、每月记录，2026-09-01已启动）。盲测期通过前，不建议实盘投入；通过后按⑥框架以≤500万、无杠杆起步。

# ADJFIX — 统一复权口径修正审计（对照计算）

- 阶段：复权口径修正审计（不动冻结数据，仅对照计算）
- 日期：2026-09-06
- 数据范围：全部冻结 episode（63,785 笔）与 STRICT_C 组合交易（96 笔）
- 2025–2026：组合表含 2025–2026 交易（为完整对照展示一并修正），但开发期结论只以 2020–2024 为准

## 1. 背景

冻结项目中：

- **信号层**：BB/MA/SD 全部使用 `close_adj = close × adj_factor`（复权价）——正确。
- **盈亏层**：episode / 组合交易的收益率使用 **不复权 raw 价直接相减**——跨除权/除息日时失真。

用户以牧原股份 002714 一笔交易（记录 −25.08%）验证：其 K 线图（前复权）显示应盈利。根因：2020-06-04 牧原除权（10 转 7 派息），复权因子 7.5891 → 12.9598；raw 口径把除权跳价误算成亏损。

## 2. 修正公式

对每一笔交易（入场日 E、出场日 X，各自当日复权因子 F_E、F_X）：

```
adj_ret = (1 + raw_ret) × (F_X / F_E) − 1
```

即：把出场价按因子比等值化到入场时的价格尺度，再算收益率。该公式与每股价格、股数、费用无关，只依赖两日复权因子，精确无近似。

- `factor_ratio = F_X / F_E ≠ 1` ⇒ 持有期跨越复权事件（分红/送转/配股），标记 `crossed = True`。
- `adj_pnl = total_cost × adj_ret`（episode）；组合 `adj_pnl = pnl × adj_ret / raw_ret`（raw_ret=0 时置 0）。
- 因子来源：`data/combined_daily.parquet` 的 `adj_factor`（tushare 复权因子，后复权价 = close × adj_factor）。零缺失。

## 3. 正确性验证（牧原）

| 口径 | 出场 2020-06-18（episode） | 出场 2020-07-06（组合） |
|---|---|---|
| raw 收益率 | −37.35% | −25.08% |
| 因子比 F_X/F_E | 1.7077 | 1.7077 |
| 修正后 adj_ret | **+6.99%** | **+27.94%** |

与手工核验的 K 线路径一致（07-06 复权收盘 1,140.2 ≈ +29.5%，扣除滑点后 +27.94% 合理）。

## 5. 结论

1. **口径混用是真实且系统性的**：13.67% 的 episode、17/96 的组合交易跨复权事件；跨除权笔中 959 笔被 raw 口径误判为亏损。
2. **修正方向几乎单边向上**：复权后平均收益、胜率、总 PnL 全面上修；极少（3 笔）因配股类事件修正为更低。
3. **信号层结论不受影响**：BB 信号本就基于复权价，此修正只改变"盈亏核算"，不改变"哪些日子出现信号"。
4. **对既有结论的影响**：任何基于 episode/组合收益率的统计（梯队排名、胜率、PnL 归因）都应以此修正版为准复核；尤其"最亏梯队"中可能有被除权跳价冤枉的股票。

## 7. 已知限制

- 配股场景：复权因子按"参与配股"计算，若实盘未参与配股，真实收益介于 raw 与 adj 之间；此类仅 3 笔，不影响总体。
- 前复权/后复权在收益率口径上等价（差常数缩放），本修正即"后复权等价数学"。
